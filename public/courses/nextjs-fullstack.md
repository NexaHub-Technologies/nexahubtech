## The idea this course installs: One codebase, two machines

Your code runs in two places — a server you control and a browser you don't — and Next.js lets you write both in one file tree. Nearly every decision it asks of you is the same question wearing different clothes: which machine should this run on, and what has to travel between them? Server or client, where to fetch, what to cache.

Once it lands, you can:

- Choose server or client deliberately, not by trial and error
- See at once why a secret must never cross the boundary
- Read caching and revalidation as questions about that line
