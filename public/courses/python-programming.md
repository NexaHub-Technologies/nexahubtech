## The idea this course installs: Names are labels, not boxes

A variable in Python is a name tied to an object, not a container holding one. Two names can point at the same list. Passing a value to a function passes the label, not a copy. This one idea explains almost every surprise a beginner runs into — mutation, identity, default arguments — and turns programming into watching data change shape rather than memorising syntax.

Once it lands, you can:

- Predict when a change is shared and when it is copied
- Read an error as a question about types and identity
- Reason about what code does before you run it
