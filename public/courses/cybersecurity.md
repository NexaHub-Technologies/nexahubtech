## The idea this course installs: Every system has a boundary, and attacks cross it

Security isn't a feature you bolt on; it is a property of where you place trust. Draw the line between what you control and what you don't, and every vulnerability turns out to have the same shape: something crossed that line and was trusted on the far side. Injection, XSS, broken authentication — each is trust granted where it was never earned.

Once it lands, you can:

- Find the trust boundary in a system you have never seen
- Recognise a new class of vulnerability as a familiar pattern
- Defend by design rather than by a checklist of patches
