## The idea this course installs: Two computers, one conversation

A browser and a server are separate machines that only ever pass text between them. One asks; the other answers. Every framework, database and deployment step you will ever meet is a refinement of that single exchange — so when something breaks, you always have a first question worth asking: which side is this happening on, and what did it actually send?

Once it lands, you can:

- Locate a bug on the right side of the wire before touching code
- Read any new framework as a variation on request and response
- Decide where a piece of data should live, and say why

03. **CSS & layout** — From the box model to modern layout — styling with intent instead of guesswork.
04. **JavaScript foundations** — Values, logic, and the DOM. How to make a page think, step by careful step.
05. **Backend with Node.js** — Servers, routes, and databases. Build an API that powers your frontend.
06. **Fullstack project** — Put it all together into a complete application you understand end to end.
