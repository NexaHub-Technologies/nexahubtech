## The idea this course installs: You describe; the browser draws

You never place a pixel yourself. You hand the browser a document and a set of rules, and it computes the result — structure first, then layout, then paint. Once CSS reads as constraints you hand a layout engine rather than positions you set by hand, “why is it doing that?” stops being a mystery and becomes a question you can reason your way to.

Once it lands, you can:

- Predict a layout instead of nudging numbers until it looks right
- Explain why a rule lost, rather than reaching for !important
- Build pages that hold up on screens you have never seen

## Modules

01. **How the web works** — The mental model first — what a browser is really doing before you write a single tag.
02. **HTML, structurally** — Markup as meaning. Build pages that are readable to people, browsers, and assistive tech.
03. **CSS & layout** — From the box model to modern layout — styling with intent instead of guesswork.
04. **JavaScript foundations** — Values, logic, and the DOM. How to make a page think, step by careful step.
05. **Building something real** — Put it together into a project you understand end to end — and can explain.
