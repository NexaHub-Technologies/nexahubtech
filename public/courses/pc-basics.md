## The idea this course installs: Everything lives somewhere

A computer never puts anything nowhere. Every document you save, every photo you copy, every app you install goes to a place that has a name — and that name is a path you can read out loud. Beginners lose work because they believe the machine decides where things go. It does not: it asks, and the answer is usually a box that got clicked past. Once you can say where a thing is, you can find it again, copy it, back it up and share it — and the fear goes with the not knowing.

Once it lands, you can:

- Find any file you have saved, on any computer, without hunting
- Say what went wrong instead of starting the whole thing again
- Move your work between a laptop, a phone and the cloud without losing it

## Modules

01. **The machine, and what it is doing** — The parts, the desktop, the mouse and the keyboard — and why nothing you click can break it.
02. **Files, folders and where things go** — Paths, saving, naming, copying and backing up. The module the whole course is built on.
03. **Documents, numbers and slides** — Write a letter properly, make a spreadsheet do the arithmetic, and build a deck worth showing.
04. **The internet, email and accounts** — Browse, search well, judge what you find, and set up an account you can get back into.
05. **Staying safe, and getting unstuck** — Scams, passwords and privacy — plus how to describe a problem well enough to be helped.

## Every session
